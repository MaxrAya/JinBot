# 🔮 Джинн-Философ: Телеграм Бот с ИИ

Репозиторий содержит исходный код асинхронного Telegram-бота **Джинна-Философа**, разработанного на языке Python.

Бот отвечает пользователям в цинично-саркастическом ключе, деконструирует любые простые запросы в глубокие экзистенциальные рассуждения и обладает выраженной ироничной индивидуальностью.

---

## 🛠️ Инструкция по запуску

### 1. Подготовка окружения
Для запуска требуется установленный Python версии 3.8 или выше. Все необходимые библиотеки (`python-telegram-bot` версии 22.8 и `openai` версии 3.x) уже установлены в текущей среде.

### 2. Настройка конфигурации (.env)
1. Убедитесь в наличии файла `.env` в корневой директории проекта (он автоматически инициализирован из `.env.example`).
2. Откройте `.env` и укажите ваш токен Telegram-бота, полученный от [@BotFather](https://t.me/BotFather):
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_bot_father
   ```
3. По умолчанию бот настроен на использование предустановленного API-ключа для доступа к модели `gemini-1.5-pro` через шлюз `https://googleapis.com`. При необходимости вы можете изменить переменные `OPENAI_API_KEY`, `OPENAI_BASE_URL` и `AI_MODEL` на собственные параметры.

### 3. Запуск бота
Запустите бота следующей консольной командой:
```bash
python bot.py
```

## 🔮 Функциональные возможности

- **Фирменная индивидуальность:** Джинн обращается к пользователям в снисходительном тоне («смертный», «мыслитель»), иронизирует над простыми арифметическими или бытовыми вопросами, а также подчеркивает свое нежелание отвечать на тривиальные темы.
- **Поддержка контекста беседы:** Бот сохраняет историю диалога (до 10 последних сообщений), что позволяет вести связный и последовательный диалог.
- **Интерфейсные команды:**
  - `/start` — Инициализирует бота и сбрасывает историю переписки.
  - `/help` — Выводит справочное сообщение.
  - `/clear` или `/reset` — Очищает историю сообщений пользователя для начала новой сессии.
